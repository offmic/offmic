End-to-end encrypted
async voice interviews.
Source-protective by design.

OffMic lets a journalist, researcher, or human rights worker collect a recorded answer from a source without exposing the recording to a third party. Audio is encrypted in the source's browser before upload. The OffMic server stores ciphertext only — we cannot read what we hold.

what it is

e2e_encryptedAES-256-GCM. Key in URL fragment, never sent to server.
browser_onlySource needs no account, no install, no Tor.
open_sourceAGPL-3.0. Fully auditable. External audit planned post-MVP.
no_logsNo analytics, no IP logging, no metadata harvesting. EU hosted.

what it is not

not SecureDropState-level adversaries → use SecureDrop.
not SignalFor real-time calls, use Signal.
not LoomStructured journalist↔source flow, not a generic recorder.
